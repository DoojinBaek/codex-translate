# Codex Translate

영어 웹페이지를 **그 자리에서** 한국어로 바꿔 주는 Aside/Chrome 확장 프로그램입니다.
API 키 없이, 이 Mac에 로그인된 **Codex(ChatGPT 구독)** 를 그대로 사용합니다.

```
확장 프로그램 ──Native Messaging──▶ bridge/host.mjs ──stdio──▶ codex app-server ──▶ ChatGPT 구독
```

- 브라우저가 필요할 때 브리지를 직접 실행하고, 브라우저를 닫으면 함께 종료합니다. 따로 띄워 둘 서버나 포트가 없습니다.
- 화면에 보이는 문단부터 작은 묶음으로 먼저 번역하고, 화면 밖 내용은 스크롤할 때 큰 묶음(기본 1500자)으로 번역합니다.
- 링크, 굵게, 인용 번호, 수식, 코드는 그대로 유지하고, 사람·기관·제품 이름은 번역하지 않습니다.
- 아이콘을 클릭하거나 **Option+A** 를 누르면 번역과 원문이 전환됩니다.

## 요구 사항

- macOS (설치 스크립트가 macOS 경로를 씁니다)
- Node.js 18 이상
- [Codex CLI](https://github.com/openai/codex) 설치 후 **본인 ChatGPT 계정으로 `codex login`**. 번역 사용량은 각자의 요금제에서 차감됩니다.
- Aside, Chrome 등 Chromium 기반 브라우저

## 설치

1. 내려받고 브리지 등록
   ```bash
   git clone https://github.com/DoojinBaek/codex-translate.git
   cd codex-translate
   ./install.sh
   ```
   `node`(18 이상), `codex` 가 설치되어 있고 `codex login` 이 되어 있어야 합니다. 설치본은 `~/Library/Application Support/codex-translate` 에 복사되고, Aside·Chrome 등 설치된 Chromium 브라우저에 Native Messaging 호스트가 등록됩니다.

2. 확장 프로그램 로드
   - `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
   - **압축해제된 확장 프로그램을 로드합니다** → `install.sh` 가 마지막에 출력하는 경로 선택
     (`~/Library/Application Support/codex-translate/extension`. 파일 선택 창에서 Cmd+Shift+G 로 붙여넣으세요)
   - 확장 ID가 `mjfjdablbdhcbjabnpnpmhapgacfcfeg` 인지 확인합니다. 브리지는 이 ID의 요청만 받습니다.
   - 업데이트할 때는 `git pull` 후 **`./install.sh` 를 다시 실행**하고, 확장 관리 페이지에서 새로고침(↻)한 뒤 열려 있던 탭도 새로고침하세요.

## 문체 설정

아이콘 우클릭 → **설정 및 사용량…** 의 맨 위 '문체' 항목에서 정합니다.

- **문체:** 합니다체 / 해요체 / 한다체(논문·기사체) / 반말 / 자동
  - **자동**은 사이트에 맞춥니다. X·Reddit·HN·YouTube는 해요체, 위키백과·arXiv 같은 논문·백과 페이지(Abstract/Introduction 제목, 논문 메타데이터 등)는 한다체, 그 밖에는 합니다체입니다.
- **사이트별 문체:** 번역할 페이지에서 아이콘 우클릭 → **이 사이트 문체** 로 그 사이트만 다르게 지정합니다. '전체 설정 따르기'를 고르면 지정이 지워집니다. 지정 목록은 설정 페이지에서 지울 수 있습니다.
- **번역 방식:** 자연스럽게(의역) / 균형(기본) / 원문에 충실(직역)
- **전문 용어:** 자동 / 영어 그대로 / 한국어로 / 한국어(영어) 병기 — 예: `역전파(backpropagation)`
- **추가 지시 (최대 1000자):** 자유롭게 적은 요청을 매 번역에 함께 보냅니다. 예: `존댓말을 쓰되 너무 딱딱하지 않게.`
- **용어집 (최대 4000자):** 한 줄에 하나씩 적습니다. 페이지에 나온 용어만 골라서 보내므로 길어도 토큰이 크게 늘지 않습니다.
  ```
  gradient => 기울기
  fine-tuning =>          # 뒤를 비우거나 "=" 를 쓰면 영어 그대로
  agent -> 에이전트       # "->", "→" 도 됩니다
  # '#' 으로 시작하는 줄은 무시합니다
  ```
- **미리보기:** 설정 페이지에서 지금 설정으로 예문을 번역해 봅니다(Codex 요청 1회, 약 7천 토큰).
- **다시 번역:** 문체를 바꾼 뒤 이미 번역된 페이지에서 Option+A 를 누르면 새 문체로 다시 번역합니다. 우클릭 메뉴 **현재 설정으로 다시 번역** 도 같습니다.

현재 페이지에 적용된 문체는 아이콘에 마우스를 올리면 보입니다(예: `문체: 한다체 (자동)`).

`~/.codex` 는 절대 수정하지 않습니다. 다만 `~/.codex/AGENTS.md` 는 Codex가 여전히 함께 보내므로, 그 안에 말투나 출력 형식 지시가 있으면 영향이 있을 수 있습니다. 문체 설정이 그보다 우선하도록 지시해 두었습니다.

## 그 밖의 설정

| 항목 | 기본값 | 메모 |
|---|---|---|
| 모델 | `gpt-6-luna` | 가장 빠릅니다. 품질을 더 원하면 `gpt-6.1-sol`. 계정에서 쓸 수 없는 모델은 비슷한 모델로 자동 대체하고 알려 줍니다 |
| 추론 강도 | `low` | 높여도 번역 품질 차이는 작고 느려집니다 |
| Fast 티어 | 꺼짐 | 켜면 조금 빨라지지만 사용량이 늘어납니다 |
| 묶음 크기 | 1500자 | 화면 밖 내용의 묶음 크기. 3000자는 토큰을 절약합니다 |
| 동시 요청 수 | 8 | 탭 하나 기준입니다 |
| 범위 | 본문만 | 우클릭 메뉴에서 '페이지 전체'로 바꿀 수 있습니다 |
| 표시 방식 | 교체 | `원문 + 번역 함께` 도 있습니다 |

## 번역 범위

- **사이트별 규칙:** X(게시물·답글·프로필 소개·카드), Reddit(글·댓글), Hacker News(제목·댓글), GitHub(README·이슈·댓글), YouTube(제목·설명·댓글), Wikipedia(본문만, 각주·내비박스 제외)
  - X 선택자는 로그인 없이 확인할 수 없었습니다. 로그인한 계정에서 게시물과 답글만 번역되는지 확인해 주세요.
- **그 밖의 사이트:** `main`/`article` 이 페이지 글의 대부분을 담고 있으면 그 안만 번역합니다. 내비게이션, 푸터, 사이드바, 메뉴, 버튼, 링크만 모인 줄은 건너뜁니다.
- 이미 한국어인 페이지와 `lang="ko"` 로 표시된 부분은 번역하지 않습니다.
- 화면 밖이나 숨겨진 요소는 보일 때만 번역하므로 접힌 메뉴는 토큰을 쓰지 않습니다. 숫자만 바뀌는 카운터(좋아요 수 등)는 다시 번역하지 않고, 계속 바뀌는 문구는 원문으로 둡니다.

## 토큰 사용량

- Codex는 코딩 에이전트라서 요청마다 고정 지시문과 도구 정의가 붙습니다. 브리지가 끌 수 있는 것을 모두 꺼서 요청당 약 **7천 토큰**으로 줄였고, 번역할 텍스트는 수백 토큰입니다. 따라서 사용량은 거의 **요청 수 × 7천** 입니다.
- **아이콘 우클릭 → 사용량** 에서 바로 볼 수 있습니다.
  - 메뉴 제목에 Codex 요금제 한도 사용률(예: `사용량 · 주간 29%`)이 표시됩니다. ChatGPT 사용량 화면과 같은 값이고, 요금제에 따라 5시간·주간 창이 나옵니다.
  - 하위 메뉴에 초기화 시각, 오늘 이 확장이 쓴 요청 수와 토큰, 지금 페이지의 토큰이 나옵니다.
  - 한도 값은 번역이 끝날 때마다 자동으로 갱신되고, "Codex 한도 새로고침"으로 직접 갱신할 수도 있습니다(토큰을 쓰지 않습니다).
- 날짜별 합계는 설정 페이지에서 볼 수 있습니다.

## 진단

설정 페이지 맨 아래 **진단** 에 브리지 버전, Codex 버전, 로그인 상태가 표시됩니다.

- **진단 실행 (Codex 요청 1회):** 짧은 문장을 실제로 번역해 첫 응답 시간과 토큰을 보여 줍니다.
- **진단 결과 복사:** 문제를 알릴 때 이 내용을 붙여 넣어 주세요(버전, 설정 단계, 로그 끝부분 포함, 로그인 토큰은 포함하지 않습니다).
- **브리지 설정 초기화:** 브리지가 이 Mac의 Codex 설정에 맞춰 자동으로 바꾼 옵션(`state.json`)을 지우고 처음부터 다시 시도합니다.
- **자세히:** 끈 MCP 서버, 제거한 설정 키, 사용 한도, 로그 끝 20줄 등을 볼 수 있습니다.

## 문제 해결

먼저 **`install.sh` 를 다시 실행**하고 확장을 새로고침하세요. 대부분 오래된 브리지가 원인입니다. 설정 페이지에 "브리지가 오래되었어요"가 보이면 이 경우입니다.

로그: `~/Library/Logs/codex-translate.log`
```bash
tail -80 ~/Library/Logs/codex-translate.log | pbcopy   # 로그 끝부분 복사
```

| 안내 | 의미와 해결 |
|---|---|
| 로그인이 만료됐거나 로그아웃 상태 | 터미널에서 `codex login` 후 Option+A |
| 사용 한도에 도달 | ChatGPT/Codex 한도 초과. 초기화 시각 이후 다시 시도하거나 가벼운 모델 선택 |
| 필수 MCP 서버를 시작하지 못함 | `~/.codex/config.toml` 에서 그 서버의 `required = true` 를 지우세요. 필수가 아닌 MCP는 브리지가 알아서 끕니다 |
| Codex 설정(config.toml) 오류 | 브리지가 문제 키를 빼고 다시 시도하는데도 실패한 경우입니다. 터미널에서 `codex` 를 한 번 실행해 오류를 확인하세요 |
| 작업을 시작하지 못함(15초 초과) + 외장 드라이브 링크 | `~/.codex` 안의 링크(예: skills)가 외장 드라이브나 보호된 폴더를 가리킵니다. 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더에서 브라우저에 접근을 허용하거나 링크를 옮기세요 |
| 테스트되지 않은 오래된 Codex | `npm i -g @openai/codex@latest` 후 `install.sh` 재실행 |
| 응답하지 않음 / 브리지가 응답하지 않음 | 네트워크(프록시·VPN)를 확인하세요. 계속되면 `install.sh` 재실행 후 브라우저 재시작 |
| 브리지가 이 브라우저에 등록되어 있지 않음 | `install.sh` 실행 후 브라우저 재시작 |
| 확장 ID가 브리지 등록과 다름 | `install.sh` 가 알려준 폴더의 `extension` 을 로드하세요 |
| 확장이 업데이트되어 연결이 끊김 | 페이지를 새로고침한 뒤 다시 번역 |

- **다른 Mac에서:** 그 Mac에서 직접 이 폴더의 `install.sh` 를 실행하고, 그 Mac의 설치 폴더(`~/Library/Application Support/codex-translate/extension`)에서 확장을 로드하세요. 설치 경로와 node/codex 경로가 Mac마다 다릅니다.
- **프록시나 `CODEX_HOME` 을 쓰는 경우:** `install.sh` 를 실행한 셸의 값이 브리지에 저장됩니다. 값이 바뀌면 `install.sh` 를 다시 실행하세요.

## 파일 구성

```
extension/            확장 프로그램 (MV3)
  background.js       아이콘/단축키, 우클릭 메뉴, Native host 연결, 사용량 기록
  content.js          문단 추출, 자리표시자(<x1>…</x1>) 직렬화, 지연 번역, 원문 전환, 문체 결정
  defaults.js         설정 기본값과 선택지
  options.html/.js    설정, 미리보기, 진단, 사용량
bridge/
  host.mjs            Native Messaging 호스트 (4바이트 길이 + JSON)
  translator.mjs      묶음 번역, 스트리밍 파싱, 재시도, 스레드 풀
  codex-client.mjs    codex app-server JSON-RPC 클라이언트
  prompt.mjs          번역 지시문(문체), 용어집
  config.mjs          Codex 설정 호환 처리 (state.json)
  errors.mjs          오류 분류와 한국어 안내
install.sh / uninstall.sh
```

## 제거

```bash
./uninstall.sh      # codex-translate 폴더 안에서
```
그다음 `chrome://extensions` 에서 확장을 삭제하세요. 로그 파일은 남겨 둡니다.

## 알려진 한계

- 이미지 속 글자, PDF, `<iframe>` 안의 내용은 번역하지 않습니다.
- 맥락 없이 한 줄만 있는 짧은 이름은 드물게 음차될 수 있습니다.
- 페이지가 같은 문단을 계속 고쳐 쓰면(티커 등) 그 문단은 원문으로 둡니다.
