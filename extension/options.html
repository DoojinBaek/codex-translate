Codex Translate

아이콘 클릭이나 Option+A로 번역과 원문을 전환해요. 아이콘을 우클릭하면 모델, 문체, 범위를 바로 바꿀 수 있어요. 변경 사항은 즉시 저장돼요.

문체

사이트별 문체
    아직 없어요. 번역할 페이지에서 아이콘 우클릭 → '이 사이트 문체'로 지정해요.

    미리보기는 Codex 요청 1회(약 7천 토큰)를 써요. 자동 문체는 합니다체로 미리 봐요.

    문체를 바꾼 뒤 번역된 페이지에서 Option+A 를 누르면 새 문체로 다시 번역해요. 우클릭 메뉴 '이 사이트 문체'로 사이트별 지정도 돼요.
